PYTHON PROGRAMS – PASS, FORMAT() AND STRING FORMAT

1. Pass Statement

for i in range(1, 4):
    pass

print("Loop completed")

Output:
Loop completed


2. Empty Condition Block

x = 10

if x > 5:
    pass
else:
    print("Less than 5")

print("Done")

Output:
Done


3. Python format() Method

name = "John"
age = 23

print("My name is {} and I am {} years old.".format(name, age))

Output:
My name is John and I am 23 years old.


4. Old String Format

name = "John"
print("Hello, %s!" % name)

Output:
Hello, John!

name = "John"
age = 23
print("%s is %d years old." % (name, age))

Output:
John is 23 years old.


5. New String Format

name = "John"
age = 23

print("My name is {} and I am {} years old.".format(name, age))

Output:
My name is John and I am 23 years old.
